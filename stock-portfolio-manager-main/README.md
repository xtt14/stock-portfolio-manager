# Stock Portfolio Manager

تطبيق إدارة محفظة الأسهم الذكية

---

## English / الإنجليزية

### Features:
- Add initial capital
- Add and manage stock transactions
- Automatic profit/loss calculation
- Display return on investment percentage
- Beautiful and easy-to-use interface
- Save data locally

### Technologies Used:
- Python 3.x
- PyQt5
- SQLite

### How to Run:
1. Download the project from GitHub
2. Extract the ZIP file
3. Double-click on `setup_and_run.bat` (Windows)
4. Use the installer window to install dependencies and launch the app

### Features:
- Input initial capital
- Add stock transactions with buy price
- Sell stocks and calculate profit/loss
- View comprehensive statistics
- View all transactions in an organized table
- Delete or modify transactions
- Data persists locally

## العربية

### الميزات:
- إضافة رأس المال الأولي
- إضافة وإدارة صفقات الأسهم
- حساب الربح/الخسارة تلقائي
- عرض نسبة العائد على الاستثمار
- واجهة جميلة وسهلة الاستخدام
- حفظ البيانات محلياً

### التقنيات المستخدمة:
- Python 3.x
- PyQt5
- SQLite

### كيفية التشغيل:
1. حمل المشروع من GitHub
2. افتح المجلد
3. اضغط مرتين على `setup_and_run.bat` (Windows)
4. استخدم نافذة التثبيت لتثبيت الحزم وتشغيل التطبيق
5. بعد التثبيت سيتم إنشاء اختصار على سطح المكتب

### الميزات المفصلة:
- إدخال رأس المال الأولي
- إضافة صفقات الأسهم مع سعر الشراء
- بيع الأسهم وحساب الربح/الخسارة
- عرض إحصائيات شاملة
- عرض جميع الصفقات في جدول منظم
- حذف أو تعديل الصفقات
- حفظ البيانات بشكل دائم
