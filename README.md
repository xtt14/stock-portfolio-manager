# Stock Portfolio Manager

تطبيق إدارة محفظة الأسهم الذكية

## الميزات:
- إدخال رأس المال الأولي
- إضافة وإدارة الصفقات
- حساب الربح/الخسارة تلقائي
- عرض نسبة العائد على الاستثمار
- تصميم جميل وسهل الاستخدام
- حفظ البيانات محلياً

## التقنيات المستخدمة:
- Python 3.x
- PyQt6
- SQLite

## كيفية التشغيل:
```bash
pip install -r requirements.txt
python main.py
```
